# Recipe Sharing Platform (Vite + React + Tailwind)

Quick start:
1. npm install
2. npm run dev
3. Open http://localhost:5173

This project contains:
- Home page (list of recipes) using mock data (src/data.json)
- Recipe detail page
- Add recipe form (client-side - adds to local state)

Note: This is a front-end demo. No backend is included.
